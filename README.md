One front page for Tuesday 17 November 2026: 21 numbered world stories from six continents, each with its source and a pin on a world map (Natural Earth 1:110m land, public domain, read from LAND_GEOJSON and not committed). The lead is the Crimean Bridge strike, followed by US strikes on Qeshm and Iranian drones at Bahrain, measles elimination status revoked for the US, Mexico and Bolivia, Mongolia's president resigning, and Alaska's Senate result. Short items follow by region. Every item comes from Wikipedia's Current events portal for 17 November 2026 and names the outlet it cites. `render.py` (Pillow) draws `entry.png`, and `main.ts` copies it to `/output/entry.png`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
